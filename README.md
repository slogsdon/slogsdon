# Shane Logsdon

Technical product leader. I spent eleven years at Global Payments building developer experience infrastructure at enterprise scale: PCI, tokenization, 3DS, ACH, the parts that matter when money moves. Now I'm building [LeadSurface](https://www.leadsurface.com).

Most of my personal work lives at the intersection of AI tooling, web standards, and developer experience. Louisville, KY.

---

## Currently building

**[LeadSurface](https://www.leadsurface.com)** turns forum noise into qualified pipeline. It monitors Reddit, HN, Discourse, and StackExchange for competitor switching signals and routes them to sales before the prospect is gone.

**[herdbot](https://github.com/slogsdon/herdbot)** runs persistent AI bots on herdr. Each bot gets a workspace, subagents run in panes, and tasks route across your Claude, Codex, Cursor, and Pi subscriptions. Written in Rust.

**[Loop & Gate](https://shane.logsdon.io/loop-and-gate/)** is the system I build LeadSurface with. The [foundation](https://github.com/slogsdon/loop-and-gate-foundation) gives an AI agent files-first memory in an Obsidian vault, and three kits add human gates for [building](https://github.com/slogsdon/loop-and-gate-build-kit), [going to market](https://github.com/slogsdon/loop-and-gate-grow-kit), and [following through](https://github.com/slogsdon/loop-and-gate-accountability-kit).

## Tooling I've open-sourced

These exist because I needed them and nothing adequate existed:

| | |
|--|--|
| [claude-code-config](https://github.com/slogsdon/claude-code-config) | My full Claude Code environment: hooks, skills, plugins, permissions. Public because other people asked. |
